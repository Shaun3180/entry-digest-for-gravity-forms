## 7. OPTIONAL - new "What's Included" cards for free features

The free feature grid doesn't yet showcase some newer free additions. If you
want to strengthen the free pitch, add cards like these (same card format as the
existing ones):

**Duplicate Digest**
> Spin up a near-identical digest in one click. Duplicate any digest, rename it, and tweak the schedule - perfect for sending the same data to different teams on different days.

**Reply-To Address**
> Set a per-digest reply-to so responses land with the right person or department, instead of your site's default mailer address.

**Pause & Resume**
> Mute a digest without deleting it. Pause keeps every setting and removes it from the schedule; resume picks right back up when you're ready.

**Test Send**
> Send a digest to any address without touching your real recipient list - confirm exactly what recipients will see before it goes live.
